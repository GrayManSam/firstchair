# Security policy

## Reporting

Use **Security → Advisories → Report a vulnerability** on the Firstchair
GitHub repository to contact the maintainers privately. Provide the affected
Firstchair and provider CLI versions, OS, impact, and a sanitized explanation of
the conditions under which the issue occurs. Keep credentials, personal data,
and production logs out of attachments and examples. Use the private advisory
thread to coordinate disclosure with maintainers.

If the private report button is unavailable, contact a maintainer directly
through the contact details on their GitHub profile. Keep security details
private while contacting them.

## Supported versions

During development, maintainers triage reports against the current default
branch and latest published prerelease in each active series. The stable
release process will document supported versions as they become available.

## Disclosure

Maintainers assess impact and affected versions, develop and validate a fix,
then publish an advisory alongside the corrected version when appropriate.
